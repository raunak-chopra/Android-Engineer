# Mobile gaming assets

Prepared on 2026-09-16 for a prospective gacha-based game.

## Reviewed sources

- [Kenney UI Pack](https://kenney.nl/assets/ui-pack) — Creative Commons CC0; free for commercial use.
- [Kenney Pixel UI Pack](https://kenney.nl/assets/pixel-ui-pack) — Creative Commons CC0; free for commercial use.
- [Kenney UI Pack - Sci-Fi](https://kenney.nl/assets/ui-pack-sci-fi) — Creative Commons CC0; free for commercial use.
- [Mobile Game Graphics Vector Game Kit](https://mobilegamegraphics.itch.io/vector-game-kit) — free download; commercial-use terms require confirmation before shipping.
- [Tareq Hadi Simple Pixel UI Pack](https://tareq-hadi.itch.io/simple-pixel-ui-pack-icons-status-bars) — explicitly free for commercial and non-commercial use; redistribution of the pack as-is is not allowed.
- [Summer Engine UI Pack](https://www.summerengine.com/asset-store/pack/ui-pack) — CC0; commercial and non-commercial use permitted.

## Local reference archives

The branch currently carries these reference archives. They are not a blanket
redistribution approval; keep the archive's license/terms with any future
integration and re-check them before shipping.

| Archive | Local evidence | Boundary |
|---|---|---|
| `hotpot-game-assets-and-resources.zip` | Two-file snapshot containing the source list README | Reference list only; no third-party assets were copied automatically |
| `kenney_interfaceSounds.zip` | Includes `License.txt` | Kenney interface sound archive; retain its license file |
| `RPGsounds_Kenney.zip` | Includes `license.txt` | Kenney RPG sound archive; retain its license file |
| `UIpack_RPG.zip` | Includes `license.txt` | RPG UI archive; retain its license file |
| `RavenmorePortraitPack.zip` | No license/terms file found in the archive listing | Hold for explicit license and redistribution confirmation |

The public itch.io pages expose temporary, session-bound download URLs; the
first automated retrieval returned an HTML page rather than an archive and was
not retained as an asset.

## Boundary

Paid packs and packs with unclear commercial licensing were excluded. Re-check each license at the time of integration and retain the source URL and license file with any downloaded archive.
