# Engineer capabilities

Inventory checked 2026-10-09. These are available workflows; their presence does not establish project or release readiness.

| Skill | Scope |
| --- | --- |
| [android-accessibility-i18n](../.codex/skills/android-accessibility-i18n/SKILL.md) | Audit Android accessibility and i18n: TalkBack, semantics, touch targets, focus, contrast, plurals, RTL, font scale, locales, and pseudolocales. |
| [android-architecture](../.codex/skills/android-architecture/SKILL.md) | Design Android boundaries, UI state, repositories, domain logic, dependency direction, and modularization. Use for cross-layer architecture decisions. |
| [android-compose-ui](../.codex/skills/android-compose-ui/SKILL.md) | Build or review Jetpack Compose and Material 3 screens, state, effects, previews, semantics, and adaptive UI. Exclude Views-only work unless migration is explicit. |
| [android-concurrency](../.codex/skills/android-concurrency/SKILL.md) | Design or debug Android Kotlin coroutine and Flow scopes, cancellation, dispatchers, sharing, backpressure, and async tests. Exclude general architecture. |
| [android-data-and-sync](../.codex/skills/android-data-and-sync/SKILL.md) | Build Android Room, DataStore, repository, paging, cache, migration, or WorkManager sync behavior. Use for durable data; exclude ephemeral UI state. |
| [android-debugging-performance](../.codex/skills/android-debugging-performance/SKILL.md) | Diagnose Android build failures, crashes, ANRs, jank, startup, memory, battery, or network performance with traces and Macrobenchmark evidence. |
| [android-navigation-adaptive](../.codex/skills/android-navigation-adaptive/SKILL.md) | Build adaptive Android navigation, route contracts, deep links, back stack, restoration, tablets, foldables, and multi-window. Exclude incidental library migration. |
| [android-networking](../.codex/skills/android-networking/SKILL.md) | Build Android HTTP clients, Retrofit or Ktor serialization, auth transport, timeout, retry, TLS, and redacted observability. Exclude cache policy. |
| [android-project-bootstrap](../.codex/skills/android-project-bootstrap/SKILL.md) | Create or change an Android Gradle project or template, modules, dependencies, convention plugins, JDK, AGP, or Kotlin setup. Exclude feature code. |
| [android-router](../.codex/skills/android-router/SKILL.md) | Route unfamiliar or cross-cutting Android work after repository inspection. Use for Android triage; exclude generic Kotlin, backend, web, and iOS-only work. |
| [android-security-release](../.codex/skills/android-security-release/SKILL.md) | Review Android security or release: permissions, secrets, signing, R8, mapping, AAB/APK, privacy, observability, and Play approval gates. |
| [android-testing](../.codex/skills/android-testing/SKILL.md) | Design Android unit, integration, Compose semantics, screenshot, instrumentation, accessibility, and release tests. Use for regression evidence, not coverage targets. |
| [application-security](../.codex/skills/application-security/SKILL.md) | Threat-model and harden authentication, authorization, sessions, input handling and privacy. |
| [backend-api](../.codex/skills/backend-api/SKILL.md) | Implement server endpoints, API contracts, background jobs and integrations. |
| [database-engineering](../.codex/skills/database-engineering/SKILL.md) | Design schemas, queries, transactions, migrations, indexes and backup recovery. |
| [engineering-router](../.codex/skills/engineering-router/SKILL.md) | Route unfamiliar mixed-platform work. Bypass for a clear specialist task. |
| [engineering-testing](../.codex/skills/engineering-testing/SKILL.md) | Design web/backend regression, integration, contract and end-to-end behavioral tests. |
| [fullstack-delivery](../.codex/skills/fullstack-delivery/SKILL.md) | Coordinate end-to-end web features across UI, services and storage. Use for cross-stack delivery. |
| [graphics-assets](../.codex/skills/graphics-assets/SKILL.md) | Create editable vectors, icons and logos; choose asset formats and export specs. |
| [kotlin-multiplatform](../.codex/skills/kotlin-multiplatform/SKILL.md) | Evaluate or build Kotlin Multiplatform shared code, source sets, platform APIs, Gradle integration, interop, and target tests when multi-target value exists. |
| [mobile-product-design](../.codex/skills/mobile-product-design/SKILL.md) | Define mobile product flows, primary actions, screen states, content, micro-interactions, adaptive behavior, and accessible implementation handoff. |
| [product-ux-design](../.codex/skills/product-ux-design/SKILL.md) | Define user needs, task flows and information hierarchy before visual design. |
| [reliability-observability](../.codex/skills/reliability-observability/SKILL.md) | Diagnose service failures and latency; design telemetry and recovery evidence. |
| [supply-chain-security](../.codex/skills/supply-chain-security/SKILL.md) | Review third-party code, agent skills, dependencies, build scripts and CI trust. |
| [system-architecture](../.codex/skills/system-architecture/SKILL.md) | Decide service boundaries, integrations, consistency and architecture migrations. |
| [visual-design-system](../.codex/skills/visual-design-system/SKILL.md) | Specify typography, hierarchy, colors, spacing and reusable visual tokens. |
| [web-frontend](../.codex/skills/web-frontend/SKILL.md) | Build web UI, forms, responsive layouts and browser accessibility. Exclude backend-only work. |
