## When to use

Use for the stated scope.

## When not to use

Focused tasks bypass this router; Android uses android-router; cross-stack web uses fullstack-delivery.

## Workflow

1. Inspect the requested output and target before choosing a route.
2. Honor an explicit available skill; preserve the chosen stack.
3. Choose one primary specialist from [map](references/routes.md) only if ownership remains unclear.
4. Add a specialist only for an affected boundary; stage multi-output work.
5. Verify the handoff; imports still require named owner approval.

## Acceptance criteria

- One coordinator at most; no whole-library preload.
- Preserve target conventions and permission boundaries.
- Record checks/omissions and obtain independent review.
