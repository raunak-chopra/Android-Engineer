## When to use

Use for the stated scope.

## When not to use

Known raster generation/edit: installed imagegen directly. UI tokens: visual-design-system. Games/3D need their own target workflow.

## Workflow

1. Inspect existing assets/style and required editable/delivery formats.
2. Prefer target-native vector/code for SVG or established icon systems.
3. For format/rights/export decisions read [exports](references/exports.md).
4. Create original assets or obtain approval before importing exact files.
5. Verify size/background/readability in the target; hand off assets and provenance.

## Acceptance criteria

- Do not convert editable vectors to raster for convenience.
- Preserve target conventions and permission boundaries.
- Record checks/omissions and obtain independent review.
