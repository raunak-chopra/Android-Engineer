# Visual system handoff
Read for a reusable design system or responsive component specification. Reuse existing semantic tokens before adding aliases. Define typography hierarchy, spacing, color roles, surfaces and focus/disabled/error/selected states. Include responsive behavior, long/localized content, contrast, zoom and reduced-motion choices where relevant. Specify component behavior without confusing it with rendered appearance. Name asset references, sizes and export requirements; do not copy another brand's identity or assets from a directory without rights review. Validate representative small/large layouts and affected states. Do not require Storybook or a component framework if the target does not use it; any new tool requires its approval. [USWDS tokens](https://designsystem.digital.gov/design-tokens/) and [GOV.UK styles](https://design-system.service.gov.uk/styles/) read 2026-10-07; adapt principles, not their brand.
