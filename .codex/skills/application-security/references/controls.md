# Security-sensitive changes

Read before modifying authentication, sessions, input handling or privacy behavior. Use a published OWASP ASVS baseline and record version/coverage. Review operation/resource/tenant authorization, session lifecycle/revocation, recovery, CSRF for the actual credential transport, contextual output handling, parameterized queries, uploads and server-side URL fetching. Use established cryptographic/auth libraries and current official docs; do not design custom crypto. Keep secrets out of browser bundles and logs; report exposure metadata without reproducing values and coordinate authorized revocation. Trace sensitive data through telemetry, exports, caches and backups. Test cross-user/tenant access, forged/expired sessions or privilege changes at the enforcing boundary. A checklist, scanner or development branch does not certify compliance.
