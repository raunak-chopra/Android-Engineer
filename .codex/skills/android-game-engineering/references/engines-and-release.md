# Engines and release
Read for engine, delivery or Play work. Engines: Godot (open source, scene and Control UI, Mobile or Compatibility renderer on phones, export via preset), libGDX with KTX (Kotlin-first, code-driven; KTX last pushed 2025-06), Unity (large plugin ecosystem; check licence and APK size), or plain Compose and Canvas for light games. Prefer the project's existing engine; compare by measured prototype, not forum opinion. Platform: frame pacing, thermal management (ADPF), Vulkan, GPU Inspector and Android vitals are on the [Android games hub](https://developer.android.com/games). Delivery: app bundles, Play Asset Delivery for large assets, 16 KB page-size readiness for native libraries. Play Games Services and [Level Up guidelines](https://developer.android.com/games/guidelines) cover profiles, achievements and cloud save; Google's published agent skills for them were Unity-only on 2026-10-12 and are advisory. Quality: [Play quality hub](https://developer.android.com/quality) and the large-screen checklist. Assets: keep code and art separate; use CC0 or licensed packs only with the licence file retained (see assets/mobile-gaming). Editor bridges (Unity or Godot MCP) are community tools: treat them as external dependencies needing approval and a sandboxed project. API 37 targets lose the large-screen opt-out; recheck game-category handling. Pages read 2026-10-12; re-check versions and policy when used.
